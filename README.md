# Project Title
**Depreciation Calculator** 📊

# Description
A small Python program that calculates a **straight-line depreciation schedule** for business assets. I built it for *BAIS:3050* to practice using GitHub and to show how I can combine accounting knowledge with technology.

# Tools Used
* Python 3
* CSV data file
* GitHub

# How to Run Program
1. Download `depreciation_calculator.py` and `assets.csv` into the same folder
2. Open a terminal in that folder
3. Run the command below

```
python depreciation_calculator.py
```

Folder layout:

```
Hello-World/
└── 
    │── README.md
    │── depreciation_calculator.py
    │── assets.csv
```

# Files Used
* `depreciation_calculator.py` – the program that reads the data and prints the schedule
* `assets.csv` – sample data file I created myself (not from an outside source)
* Contents of `assets.csv`: asset name, cost, salvage value, and useful life in years
* Data considerations: the numbers are made-up examples, and you can edit the file to add your own assets

# Additional Documentation
> Formula used: (Cost − Salvage Value) ÷ Useful Life = Annual Depreciation
